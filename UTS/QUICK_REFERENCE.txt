CELL 4: DATA PREPROCESSING
───────────────────────────────────────────────────────────────────────────────
# Create working copy
df_processed = df.copy()

# Handle missing Departemen dengan MODE (nilai terbanyak)
mode_dept = df_processed['Departemen'].mode()[0]  # 'HRD' (paling sering)
df_processed['Departemen'].fillna(mode_dept, inplace=True)

# Handle missing Gaji dengan MEDIAN
median_gaji = df_processed['Gaji'].median()        # Rp 5,040,414
df_processed['Gaji'].fillna(median_gaji, inplace=True)

# KATEGORISASI GAJI (Create Target Variable)
Q1 = df_processed['Gaji'].quantile(0.33)  # 33rd percentile
Q2 = df_processed['Gaji'].quantile(0.67)  # 67th percentile

def kategorikan_gaji(gaji):
    if gaji < Q1:
        return 'Rendah'
    elif gaji < Q2:
        return 'Sedang'
    else:
        return 'Tinggi'

df_processed['Kategori_Gaji'] = df_processed['Gaji'].apply(kategorikan_gaji)

─── Why These Choices? ───
- MODE untuk kategorik: Imputation paling sensible
- MEDIAN untuk numerik: Robust terhadap outliers
- KUARTIL untuk kategorisasi: Balanced classes (~33% per class)

- Menyimpan encoder untuk inverse transform nanti

CELL 7: TRAINING MODEL
───────────────────────────────────────────────────────────────────────────────
from sklearn.naive_bayes import GaussianNB

model = GaussianNB()              # Inisialisasi model
model.fit(X_train, y_train)       # Training dengan X_train dan y_train

─── What Happens Inside ───
Model menghitung untuk setiap class (Rendah, Sedang, Tinggi):
1. Prior probability: P(C) - berapa % sampel per class
2. Mean (θ): rata-rata setiap fitur per class
3. Variance (σ²): varians setiap fitur per class

Stored dalam:
- model.class_prior_     # P(C)
- model.theta_           # mean per fitur
- model.var_             # variance per fitur
- model.classes_         # daftar class names

recall = recall_score(y_test, y_pred, average='weighted')
f1 = f1_score(y_test, y_pred, average='weighted')

─── Metrics Explanation ───
Accuracy:  (TP+TN) / Total
          → Berapa % prediksi benar dari semua prediksi

Precision: TP / (TP+FP)
          → Dari yang diprediksi POSITIVE, berapa % benar?

Recall:    TP / (TP+FN)
          → Dari yang seharusnya POSITIVE, berapa % ketangkap?

F1-Score:  Harmonic mean dari Precision & Recall
          → Balance antara precision dan recall

═══════════════════════════════════════════════════════════════════════════════
🧮 MATHEMATICAL FLOW DALAM NAÏVE BAYES
═══════════════════════════════════════════════════════════════════════════════

STEP 1: COMPUTE PRIOR PROBABILITY
──────────────────────────────────────
P(Rendah) = jumlah sampel Rendah / total sampel
          = 50 / 160 = 0.3125

P(Sedang) = 51 / 160 = 0.3187
P(Tinggi) = 59 / 160 = 0.3688


STEP 2: COMPUTE LIKELIHOOD (UNTUK SATU SAMPLE BARU)
──────────────────────────────────────────────────────
Sample baru: Usia=28, Lama_Kerja=2, Departemen=HRD(0), Status=Kontrak(0)

Untuk class RENDAH:
P(Usia=28|Rendah) = Gaussian(28, μ=43.34, σ²=111.46)
                  = (1/√(2π·111.46)) · exp(-(28-43.34)²/(2·111.46))
                  = 0.0298

P(Lama_Kerja=2|Rendah) = Gaussian(2, μ=14.78, σ²=63.73)
                       = 0.0158

... similar untuk fitur lainnya ...

STEP 3: MULTIPLY ALL LIKELIHOODS
──────────────────────────────────
P(Features|Rendah) = P(Usia|Rendah) × P(Lama_Kerja|Rendah) × ... 
                   = 0.0298 × 0.0158 × ...
                   = 0.000123 (contoh)

STEP 4: APPLY BAYES THEOREM
─────────────────────────────
P(Rendah|Features) ∝ P(Features|Rendah) × P(Rendah)
                   ∝ 0.000123 × 0.3125
                   ∝ 0.0000384

Lakukan sama untuk P(Sedang|Features) dan P(Tinggi|Features)

STEP 5: NORMALIZE (GET PROBABILITIES)
───────────────────────────────────────
Total = 0.0000384 + 0.0000412 + 0.0000401 (hypothetical)

P(Rendah|Features) = 0.0000384 / Total = 0.3194
P(Sedang|Features) = 0.0000412 / Total = 0.3429
P(Tinggi|Features) = 0.0000401 / Total = 0.3376

STEP 6: PREDICT
────────────────
Class dengan probability tertinggi = SEDANG (0.3429)
PREDICTION = "SEDANG"
